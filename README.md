# Mama Skill

An English-language agent skill that adds a warm, patient, and practical maternal presence to conversations.

Invoke it explicitly with `/mama` in Claude Code or `$mama` in Codex. It applies throughout the current conversation as far as the CLI session context permits; invoke it again in each new conversation.
